# Wisp 使用说明

适用于 0.1 系列版本。安装、权限与接入模型见仓库根目录的 [README](../README.md#安装)，各家模型服务的细节见[模型服务](providers.md)；这里讲日常怎么用、每个设置项是什么意思，以及出问题时怎么排查。

**按键约定**：文中按 macOS 书写。在 Windows / Linux 上，<kbd>⌘</kbd> 换成 <kbd>Ctrl</kbd>，<kbd>⌥</kbd> 换成 <kbd>Alt</kbd>，<kbd>↩</kbd> 是 <kbd>Enter</kbd>，<kbd>⌫</kbd> 是 <kbd>Delete</kbd>；全局快捷键三端不同，见[快捷键速查](#快捷键速查)。界面里出现的快捷键总是按你当前的绑定显示。

## 开始之前

**首次启动的引导**有三步，可以跳过，之后随时从托盘的「使用引导…」重新进入：

1. **权限**（只在 macOS 上出现）：辅助功能（读取选中的文字、自动粘贴）与屏幕录制（截图 OCR）。授权后状态实时变绿；屏幕录制需要点「重新启动 Wisp」才会生效。
2. **接入模型**：选 OpenAI、Anthropic、Gemini 或其他服务，填 Key，测试连接，再选翻译与 OCR 的默认模型。不想填 Key 时，点这一步下方的「不想填 API Key？使用离线模型」，选一档离线模型在后台下载（见[离线模型](#离线模型)）。已经在其他设备上用 Wisp 时，可以点这一步下方的「已在其他设备上使用 Wisp？连接同步」，直接去「设置 → 同步」连接，模型服务与 Key 会从其他设备同步过来（见[多设备同步](#多设备同步)）。
3. **试一试**：在示例文字上按一次划词翻译，再按一次剪贴板。

**托盘 / 菜单栏菜单**：

| 项 | 作用 |
| --- | --- |
| 状态行 | 正常时显示「Wisp 正在运行」；缺少权限、有快捷键没生效、剪贴板记录已暂停、同步需要处理、有新版本时显示对应提示，点一下直接去处理 |
| 划词翻译 / 翻译输入… / 截图 OCR / 截图直接翻译 / 剪贴板 | 与全局快捷键相同的五个动作 |
| 显示固定窗口 | 把所有固定窗口带到前面 |
| 暂停剪贴板记录 | 临时停止记录，再点一次恢复 |
| 清空剪贴板历史… | 删除全部记录（可以保留收藏）；同步剪贴板历史时，其他设备上的记录也会一并清除 |
| 立即同步 | 开启了同步时出现，马上同步一次 |
| 设置… / 使用引导… / 检查更新 / 退出 | — |

**面板**是所有结果共用的小窗口：出现在选区、光标或屏幕中央，不抢走原应用的焦点（剪贴板和输入翻译需要打字，这两种会获得焦点）。<kbd>Esc</kbd> 永远可以关闭它。

## 划词翻译

在任意应用里选中文字，按 <kbd>⌥ D</kbd>。

Wisp 先通过系统的无障碍接口读取选中的文字（macOS 辅助功能、Windows UI Automation、X11 的 PRIMARY 选区）；读不到时模拟一次复制，读完把剪贴板原样还原。两种方式都没拿到文字时，面板以**输入模式**打开。

### 面板上有什么

```text
┌──────────────────────────────────────────┐
│ 英语 → 中文 ▾              自然 ▾   ⋯  ✕ │  语言条 · 风格 · 更多 · 关闭
│ 译文逐字流出……                            │  正文
│ gpt-5.4-mini · 1.2 s · 86 tokens  ⧉ 📌 ⇄ ⤢ │  模型 · 耗时 · 用量 · 复制 / 固定 / 原文 / 展开
└──────────────────────────────────────────┘
```

- **语言条**：自动检测原文语言。原文不是目标语言时译成目标语言，已经是目标语言时译成第二语言（默认目标中文、第二语言英文，在「设置 → 翻译」里改）。点语言条可以交换方向或临时换一种目标语言，只对这一次有效。
- **风格**：点风格名展开菜单，或用 <kbd>⌘ 1–9</kbd> 直接切换、<kbd>⌘ ↑ / ↓</kbd> 依次切换。换风格后旧译文变淡，新译文到达时交叉淡入。
- **流式中**：底栏有「停止」按钮，也可以按 <kbd>⌘ .</kbd>，已经收到的部分会保留。
- **完成后**：复制（<kbd>⌘ C</kbd>：有选区时复制选中部分，否则复制全部译文）、固定（<kbd>⌘ P</kbd>）、原文对照（⇄）、展开（⤢，在更大的固定窗口里同时显示原文和译文）。

### 翻译风格

| 风格 | 适合 |
| --- | --- |
| 自然（默认） | 通顺自然，贴近母语表达 |
| 技术 | 术语准确，保留代码、命令与专有名词 |
| 学术 | 正式严谨，适合论文与报告 |
| 口语 | 轻松口语，适合聊天与社交 |
| 学习 | 译文之外附带词汇与语法讲解 |
| 直译 | 逐句直译，便于对照原文 |

每个风格都可以在「设置 → 翻译 → 风格」里修改提示词（可以一键还原）、改输出格式（纯文本 / Markdown）、调温度、绑定专用模型和全局快捷键。也可以新建自定义风格。风格列表的顺序就是 <kbd>⌘ 1–9</kbd> 的顺序，拖动左侧把手即可调整。

**词典式**：选中的是单个单词或短语时（风格里「短文本用词典式」开着），结果按词典排版：音标、词性、编号的释义与例句。

### 「⋯」菜单

| 项 | 作用 |
| --- | --- |
| 润色 | 改进原文的表达（不翻译），显示正文与改动 |
| 校对 | 找出原文里的错别字和语法问题，逐处标出改动 |
| 提升译文（<kbd>⌘ ⇧ R</kbd>） | 让模型检查并改进当前译文；原文至少 40 词或 60 字时可用。完成后可以在原译文与提升后的译文之间切换 |
| 复制原文 | — |
| 切换模型 | 只对这一次生效；默认值在「设置 → 模型与服务」。这台设备上已下载的离线翻译模型排在最前 |
| 编辑当前风格 | 打开设置里的风格编辑器 |

### 其他行为

- **重新生成**：<kbd>⌘ R</kbd>。10 分钟内重复翻译同一段文字时直接用缓存（状态行显示「来自缓存」），<kbd>⌘ R</kbd> 会绕过缓存重新请求。
- **长文本**：超过 3000 字（可调）时先显示字数、预计 token 与耗时，确认后才翻译；特别长的文本会提示译文可能被截断。
- **输入翻译**：<kbd>⌥ ⇧ D</kbd>，或划词时没有拿到文字。在输入框里打字或粘贴，<kbd>↩</kbd> 换行，<kbd>⌘ ↩</kbd> 翻译。
- **固定窗口**：<kbd>⌘ P</kbd> 把结果「固定」成一个可拖动、可调整大小、默认置顶的窗口，面板随即可以继续用。流式中固定也不会中断。
- **关闭面板**：<kbd>Esc</kbd>、<kbd>⌘ W</kbd>、点击面板外（默认开启），或者鼠标离开面板一段距离（默认关闭）。
- **术语表**：在「设置 → 翻译 → 术语表」里指定某个词的译法；译文与原文相同表示保持不译（例如「Tauri → Tauri」）。命中的术语优先于风格规则。支持从 JSON / CSV / TSV 导入，导出为 JSON 或 CSV。

## 截图 OCR

按 <kbd>⌥ S</kbd>，屏幕定格并变暗，然后：

| 操作 | 结果 |
| --- | --- |
| 拖动 | 框选区域；旁边显示尺寸（macOS 为 pt，Windows / Linux 为 px）和像素放大镜 |
| 拖动中按住空格 | 平移整个选区，松开空格继续调整大小 |
| 鼠标停在窗口上、单击 | 选中整个窗口（「识别窗口」开着时） |
| <kbd>⌘ A</kbd> | 选中整个屏幕，再按 <kbd>↩</kbd> 确认 |
| <kbd>↩</kbd> | 确认当前选区 |
| <kbd>Esc</kbd> | 取消 |

多显示器时每个屏幕都会定格，选区限制在开始拖动的那块屏幕上。松手的同时请求就发出去了，选区飞向结果面板（「飞入动效」可以关掉）。

### 结果面板

- **头部**：截图缩略图（点一下放大查看）、尺寸、识别模式与模型。
- **正文**：识别中显示骨架动画，文字逐段出现。用离线模型第一次识别时先显示「正在加载离线模型…」，PaddleOCR 的任务接口排队时显示「云端处理中…」。完成后可以直接编辑，状态行会标出「已编辑」。默认识别完成时自动复制到剪贴板（「已复制」）。
- **识别出的内容**：文字里有电话、邮箱、链接、验证码、单号等时，底栏上方排出一行芯片，单击把这一段粘贴回原来的应用（面板随之收起；固定窗口里改为复制），<kbd>⌥</kbd> 单击只复制；编辑文字后会重新识别。种类与剪贴板共用「设置 → 剪贴板 → 智能识别」的开关（见[识别出的内容](#识别出的内容)）。
- **底栏**：排版 ▾ · 复制 · 翻译 ▾ · 重新识别 ▾ · 固定。
  - **排版 ▾**：纯文本与段落模式下，在「原样」「去掉空行」「合并为一行」之间切换，纯文本模式另有「合并段内换行」（见下文[排版](#排版)）；结构化模式下这个位置是「显示 Markdown 源码」。
  - **翻译**：在同一面板下半部分给出译文，有自己的语言条、风格与复制按钮；以面板里显示的文字（换过的排版、你的修改）为原文，只切换排版不会重新翻译。有文字时 <kbd>⌘ 1–9</kbd> 直接用对应风格翻译。
  - **重新识别 ▾**：切换识别模式或识别模型（已下载的离线模型、PaddleOCR 的模型与视觉模型）、重新截图、打开识别历史与 OCR 设置。编辑过的文字被重新识别覆盖之前会先确认。重新识别后，新结果的自动复制替换上一次在剪贴板历史里新建的那一条，不会每识别一次多一条；识别出的文字没变时沿用原来那一条。期间复制过别的内容、那一条收藏过，或者识别被取消、失败时，不删。
- <kbd>⌘ R</kbd> 作用于你最后操作的那一块：识别文字 → 重新识别，译文 → 重新翻译。
- <kbd>⌘ ↩</kbd> 把当前的文字粘贴回截图前的应用，面板随之收起，改完文字不用再 <kbd>⌘ C</kbd>、<kbd>Esc</kbd>、<kbd>⌘ V</kbd>。粘贴的就是 <kbd>⌘ C</kbd> 会复制的那段（选中部分；没有选中时，展开了译文就是译文，否则是识别文字），与芯片一样不另记一条剪贴板历史。在文本框里按也不会换行；还在识别或翻译时不粘贴；固定窗口里，或者没能粘贴时，改为复制。
- **焦点**：面板不抢原应用的键盘。点复制按钮、芯片或排版按钮的左半边时，键盘仍留在原来的应用里，回去直接 <kbd>⌘ V</kbd> 即可；点面板上的其他地方（文字、其他按钮与各个 ▾、菜单、语言条、头部或空白处）照常让面板取得键盘。所以 <kbd>⌘ C</kbd>、<kbd>⌘ L</kbd>、<kbd>⌘ ↩</kbd> 这些面板里的键，要先点一下文字或空白处才生效。macOS 与 Windows 都是这样；Linux 上取决于窗口管理器是否遵守面板「不接受焦点」的设置，在只能由面板自己写剪贴板的 Wayland 会话里，点复制时面板会先取得键盘再复制。

### 识别模式

| 模式 | 输出 | 适合 |
| --- | --- | --- |
| 纯文本（默认） | 逐行转录，保留原来的换行与缩进 | 代码、表单、诗歌、界面文字 |
| 段落 | 合并段落内的断行 | 文章、PDF、网页正文 |
| 结构化 | 标题、列表、表格转为 Markdown | 文档、幻灯片、表格 |

段落模式里段落之间、标题前后空一行；连续的列表项、表格行，以及按钮、标签、菜单项这类短的界面元素每项一行，彼此之间不空行，折成几行的列表项也合成一行。用模型服务识别时，表格同一行的单元格之间以制表符隔开，粘贴进表格软件时各占一格。

结构化的结果里有表格或公式时，默认显示预览：表格画成真正的表格（放不下时在表格内左右滚动），公式以源码显示，可以单独复制。点底栏的「显示 Markdown 源码」切回可以编辑的源码，再点一次回到预览；没有表格与公式时直接显示源码。

默认模式在「设置 → OCR」里改，单次可以从「重新识别 ▾」切换。离线的 PP-OCRv6 与 PaddleOCR 的 PP-OCRv6 只识别文字，不支持结构化：菜单里这一项置灰并说明原因，默认模式是结构化时按段落识别。它们在段落模式下合并断行的规则与剪贴板的[「合并为一行」](#粘贴为)相同，以 ⑴、❶、「一、」、「a.」、1.2.3 这类编号开头的行另起一段；连续的列表项与短行之间只换行，版面上明显隔开的两组之间仍空一行。

### 排版

纯文本与段落模式的识别结果会先整理空白：去掉每行末尾的空格、制表符与全角空格，连续的空行只留一行，开头和结尾不留空行；行首缩进与行内的空格不变，也不会合并行。结构化与截图直接翻译的结果保持原样。

在这之上，底栏的排版按钮可以随时换一种排版，识别出的文字本身不变：

| 排版 | 效果 |
| --- | --- |
| 原样（默认） | 保留识别出的换行与空行 |
| 去掉空行 | 删掉所有空行，其余每行原样保留，段落之间不再空一行 |
| 合并段内换行 | 只在纯文本模式：以空行分段，把段内被硬换行断开的行连成一行，列表、表格、短行与看得出是代码或日志的行不动，规则与局限同剪贴板的[「合并段内换行」](#粘贴为)，适合从 PDF 截来的文字；代码与终端输出建议保持原样 |
| 合并为一行 | 所有行连成一行，规则同剪贴板的[「合并为一行」](#粘贴为)，适合搜索框与字幕 |

- 按钮左半边在「原样」与这次最近用过的整理方式之间切换，<kbd>⌘ L</kbd> 效果相同（与 <kbd>⌘ C</kbd>、<kbd>⌘ R</kbd> 一样，先点一下文字或面板空白处；点排版按钮不会让面板取得键盘，见[焦点](#结果面板)）；▾ 列出当前模式可用的几种（纯文本模式四种，段落模式三种），对当前文字不适用的置灰（例如没有空行、只有一行时）。用过「合并段内换行」后换成段落模式重新识别时，结果按原样显示与复制，左半边改为「去掉空行」。
- 开着「自动复制结果」时，切换后剪贴板随之换成新的版本，状态行再次显示「已复制」，回到原来的应用直接 <kbd>⌘ V</kbd> 即可；剪贴板历史里自动复制的那一条随之替换，不会每切换一次多一条（收藏过的不删）。识别完成后又复制过别的内容、文字改过，或者在固定窗口里切换时，不会改动剪贴板。
- 改过文字后排版按钮置灰，▾ 菜单里出现「放弃修改，恢复识别结果」，确认后恢复为识别结果。
- 默认排版在「设置 → OCR → 识别之后 → 排版」里选：原样或去掉空行（合并段内换行与合并为一行只能单次切换）。自动复制与识别历史用识别完成时的排版；之后切换排版不会改写识别历史。

### 截图直接翻译

按 <kbd>⌥ ⇧ S</kbd>，框选后面板直接显示译文。需要对照时点底栏的「原文」，Wisp 会按需转录一次原文并缓存。想每次都同时得到原文，打开「设置 → OCR → 截图翻译时附原文」（会多一次请求）。OCR 模型是离线模型或 PaddleOCR 时分两步：先识别出原文，再用翻译模型翻译；翻译也选了离线模型时，全程都在这台设备上完成。

### 识别历史

默认关闭。在「设置 → OCR → 识别历史」打开后，Wisp 保存最近的识别结果与截图（默认 50 条，10–500 可调），可以回看、复制、重新翻译或删除。识别历史保存在这台电脑上；开启了[多设备同步](#多设备同步)并勾选「识别历史」时，会加密后同步到你的其他设备，在这里删除或清空记录，其他设备上的对应记录也会删除（清空时的确认会注明）。关闭时会询问是否一并清空已保存的记录。

## 剪贴板

Wisp 在后台记录你复制的内容。按 <kbd>⌥ V</kbd> 唤出面板，焦点已经在搜索框里，直接打字即可。

### 找到条目

- **搜索**：输入即搜，不区分大小写。输入 3 个字及以上时检索全部历史；1–2 个字时在最近 2000 条里查找（中文一两个字也能搜到）。收藏的名称也能搜到。
- **筛选**：<kbd>Tab</kbd> / <kbd>⇧ Tab</kbd> 在「全部、收藏、文本、图片、文件、链接、代码、颜色」之间切换，<kbd>⌘ F</kbd> 打开筛选菜单。
- **移动**：<kbd>↑ ↓</kbd> 选择，<kbd>⌘ ↑ / ↓</kbd> 跳到第一条 / 最后一条，<kbd>PageUp / PageDown</kbd> 翻一屏。按住 <kbd>⌘</kbd> 时每行显示 1–9 的角标。
- **预览**：鼠标悬停显示多行文本或大图；<kbd>Space</kbd>（搜索框为空时）或 <kbd>⇧ Space</kbd> 打开全文 / 原图预览。

| <kbd>↩</kbd> 或单击 | 粘贴到原来的应用（面板先隐藏、焦点回到原应用，再替你按下粘贴键） |
| <kbd>⇧ ↩</kbd> | 粘贴为纯文本（去掉格式） |
| <kbd>⌘ ↩</kbd> | 只复制，不粘贴 |
| <kbd>⌥ ⇧ ↩</kbd> | 粘贴为…（见下文[粘贴为…](#粘贴为)） |

| <kbd>⌘ K</kbd> 或右键 | 操作菜单：以上全部，加上命名、提取、图片另存为、识别文字、打开链接、在访达 / 资源管理器中显示、翻译、折叠收藏、暂停记录、清空历史、剪贴板设置 |
| <kbd>Esc</kbd> | 先关闭预览、取消多选，再清空搜索，最后关闭面板 |

鼠标点击条目即粘贴；习惯双击的话在「设置 → 剪贴板 → 粘贴方式」里改。

**终端里粘贴**：GNOME Terminal、Konsole 等终端的粘贴键不是 <kbd>Ctrl + V</kbd>，Wisp 已内置常见终端的粘贴键；其他应用可以在「设置 → 剪贴板 → 应用内粘贴键」里补充。

**只复制、没有粘贴进去**时，面板原位会短暂提示原因，内容已经在剪贴板里，手动粘贴即可：

| 提示 | 原因 |
| --- | --- |
| 未授予辅助功能权限，无法自动粘贴 | macOS 缺少辅助功能权限，提示里有授权按钮 |
| 目标应用以管理员身份运行，无法自动粘贴 | Windows 不允许普通程序向管理员窗口发送按键 |
| 原来的应用已经关闭 / 没能及时切回原来的应用 | 目标窗口不在了，或切换焦点超时 |
| Wayland 下无法替你按下粘贴键 | Linux Wayland 会话的限制 |

**拖出**：把一行文字、链接或富文本拖进其他应用即可放入内容（链接可以直接拖到浏览器地址栏）；选择了多条时拖出的是合并后的文字。图片与文件暂时不能拖出。

### 收藏

- <kbd>⌘ D</kbd> 收藏或取消收藏。收藏的条目不受「最多保留」与「保留时间」的限制，清空历史时也可以保留；删除时要再按一次确认。
- 列表顶部是「收藏」分组，下面是「最近」。「全部」里最多列出 5 条收藏，更多时分组末尾有一行「查看全部 N 个收藏」，点它切到收藏视图；筛选里的「收藏」同样列出全部收藏。
- 点「收藏」分组的标题可以折叠或展开（「⋯」菜单里也有「折叠收藏」「展开收藏」）。折叠状态只记在这台设备上。
- **命名**：在 <kbd>⌘ K</kbd> 或右键菜单里选「命名…」（已有名称时是「重命名…」），在面板底部的输入条里写名称，<kbd>↩</kbd> 确认、<kbd>Esc</kbd> 取消；留空则去掉名称。命名会同时收藏这一条。名称最多 64 个字，加粗显示在条目上，搜索时也能按名称找到。

### 识别出的内容

Wisp 会从条目里认出电话、邮箱、链接、验证码这类内容，让你只粘贴需要的那一段。识别只在本机进行，不经过模型。

- 光标停在含有这类内容的条目上时，列表底部出现一行芯片；悬停预览、全文预览与 OCR 结果里也有。**单击芯片**粘贴这一段，<kbd>⌥</kbd> 单击只复制。
- 键盘：<kbd>⌘ E</kbd> 把焦点移到芯片上，<kbd>← →</kbd> 选择，<kbd>↩</kbd> 粘贴，<kbd>⌥ ↩</kbd> 只复制，<kbd>Esc</kbd> 回到列表。操作菜单里的「提取」列出同样的内容。
- 粘贴的片段不会另记一条历史。
- 在「设置 → 剪贴板 → 智能识别」里按种类开关：

| 种类 | 包括 | 默认 |
| --- | --- | --- |
| 联系方式与链接 | 邮箱、电话、网址与 IP 地址 | 开 |
| 验证码 | 短信和邮件里的验证码 | 开 |
| 单号与数字 | 快递单号、订单号、金额与日期时间 | 开 |
| 证件与银行卡号 | 身份证号与银行卡号；芯片上遮住中间几位，粘贴时是完整号码 | 关（属于敏感信息） |

**验证码自动删除**：复制的验证码会被认出来，行内显示「验证码 · N 分钟后删除」，复制 10 分钟后自动从剪贴板历史中删除；收藏的验证码不会删除。不需要时关闭「设置 → 剪贴板 → 智能识别 → 验证码 10 分钟后自动删除」。开启了多设备同步时，其他设备上的同一条也按同一时间各自删除；到期前在任意一台设备上收藏了它，各台设备都会保留（见[剪贴板怎么同步](#剪贴板怎么同步)）。

### 粘贴为…

<kbd>⌥ ⇧ ↩</kbd>，或在 <kbd>⌘ K</kbd> / 右键菜单里选「粘贴为」，把文字变换之后再粘贴：合并为一行、合并段内换行、去掉空行、去掉首尾空白、全部大写、全部小写、首字母大写、转为半角、转为全角、格式化 JSON、压缩 JSON、去掉跟踪参数。菜单里只列出对这一条适用的变换（例如 JSON 的两项只对能解析的 JSON 出现，「去掉跟踪参数」只对带跟踪参数的链接出现）。变换后的结果直接粘贴，不另记一条历史，原来的条目不变。

- **合并为一行**按文字的写法连接各行：中文、日文之间直接相连，中文的破折号、省略号后面也不加空格；英文与韩文保留词间空格；行尾的连字符断开一个单词时去掉，COVID-19、Wi-Fi、2020-2021 这类本来就带连字符的照原样保留、不插入空格；中文与英文或数字之间是否加空格跟随原文的习惯（原文里中英之间多数有空格时才加）。
- **合并段内换行**适合从 PDF、网页复制来、每行末尾都断开的段落：以空行分段，段内的行按「合并为一行」的方式连起来，段落之间的空行保留。它只看文字判断，宁可少合并：列表项、表格与按空格对齐的列，以及有明显特征的代码、命令与日志行（有缩进，以 `;` `{` `}` 结尾，以提示符 `$ `、时间戳、提交号或 `import` 开头等）保持原样，「名称：」开头的行（包括 `Request URL:` 这样几个大写开头的词）另起一行，单独成行的短行（不到约 10 个汉字或 20 个字母，例如标题、菜单项）不与下一行相连。没有这些特征的代码、终端输出与日志仍可能被合并，这类内容请直接粘贴原文；段落之间既没有空行也没有首行缩进时，下一段可能接到上一段末尾。只对文字与富文本条目出现，代码条目里的换行有含义，不提供这一项。
- **去掉空行**删掉空行与只有空白的行，其余每行原样保留（缩进、行尾空格与 Windows 换行都不变），不合并行。

### 多选与连续粘贴

- **选择**：<kbd>⌘</kbd> 单击选择或取消一条，<kbd>⇧</kbd> 单击选择一段，<kbd>⇧ ↑ / ↓</kbd> 向上 / 向下扩展。行首按选择的顺序显示编号；已经有选择时，单击也是选择或取消。<kbd>Esc</kbd> 取消选择。
- **合并粘贴**：<kbd>↩</kbd> 按选择的顺序以换行连接后粘贴，<kbd>⇧ ↩</kbd> 合并粘贴为纯文本；合并的结果不另记一条历史。选择的条目也可以一起收藏（<kbd>⌘ D</kbd>）、删除（<kbd>⌫</kbd>，含收藏时要再按一次）或拖出。
- **连续粘贴**：选择两条以上后按 <kbd>⌘ ↩</kbd>（或在菜单里选「连续粘贴」）。第一条立即粘贴，之后在任何应用里每按一次 <kbd>⌘ V</kbd>（以及「应用内粘贴键」里各应用的粘贴键，例如终端的 <kbd>Ctrl + Shift + V</kbd>）就粘贴下一条，原来面板的位置会提示进度，例如「连续粘贴 · 2 / 5」（从悬浮剪贴板开始时，进度显示在悬浮窗底部）。按住 <kbd>⌘</kbd> 连按 <kbd>V</kbd> 也是一次一条，按键的自动重复不会跳过条目。
- **结束**：全部粘贴完、在任何应用里按 <kbd>Esc</kbd>、点托盘状态行「连续粘贴 n / m · 点击结束」、选「⋯ → 结束连续粘贴」、锁屏，或 10 分钟没有再粘贴，都会结束。
- 为了做到这一点，Wisp **只在连续粘贴进行期间**临时接管粘贴键与 <kbd>Esc</kbd>，结束后立即恢复，平时不拦截任何按键。macOS 需要辅助功能权限（与自动粘贴相同）。Windows 上前台是以管理员身份运行的窗口时，粘贴键原样生效、不会前进到下一条。Linux X11 上松开 <kbd>V</kbd> 之后才粘贴下一条；**Wayland 会话不支持连续粘贴**，菜单里会显示为「连续粘贴（当前会话不支持）」。

### 悬浮剪贴板

按 <kbd>⌘ P</kbd> 或点剪贴板头部的「悬浮」按钮，剪贴板变成一个可以一直开着的小窗口：面板随即收起，悬浮窗接着刚才的搜索、筛选与光标。第一次打开时它出现在面板原来的位置，之后在你上次放的位置。

- **点一条就粘贴进正在使用的应用**：悬浮窗不抢焦点，粘贴之后光标仍在原来的应用里，悬浮窗留在原处。需要搜索时点搜索框即可打字，之后点条目仍然粘贴回原来的应用。
- 默认置顶，头部的「置顶」开关可以取消；可以拖动、调整大小，下次打开时记住位置、大小与是否置顶。
- 内容实时更新：新复制的内容直接出现在列表里；开启了同步时，指针移入或窗口获得焦点后取回其他设备的新条目。
- 文字与链接可以直接从悬浮窗拖进其他应用；多选、收藏、粘贴为与连续粘贴同样可用。
- <kbd>Esc</kbd> 先清空搜索与选择，再把键盘交还给原来的应用（窗口不关）；<kbd>⌘ W</kbd> 或 ✕ 关闭。截图 OCR 时悬浮窗暂时隐藏，不会被截进去。
- Wayland 会话下点条目只复制，提示你自己按 <kbd>Ctrl + V</kbd>。

### 图片识别文字

图片条目的 <kbd>⌘ K</kbd> / 右键菜单与大图预览里有「识别文字」：面板切到 OCR 结果，用你的 OCR 模型识别这张图片，之后与[截图 OCR](#截图-ocr)一样可以编辑、复制、翻译、重新识别与固定。

### 记录什么、不记录什么

- 记录文本、富文本、图片与文件（只记路径，源文件被删除后条目会变灰），可以在设置里按类型关闭。同样的内容再复制一次不会重复，只会移到最上面。
- **不记录**：看起来像密码、令牌或私钥的内容（托盘图标会闪一下表示跳过了一条）；排除名单里的应用复制的内容（默认包含 1Password、Bitwarden、KeePassXC 等密码管理器）；应用标记为「不要记录」的内容（密码管理器通常会这样做）。
- **暂停**：托盘「暂停剪贴板记录」或面板的「⋯ → 暂停记录」，面板顶部会显示「剪贴板记录已暂停」。
- **保留**：默认最多 1000 条（不含收藏）、不限天数；单条文本上限 1 MB，单张图片上限 20 MB。超出的部分在空闲时自动清理。验证码另有 10 分钟的自动删除（见[识别出的内容](#识别出的内容)）。

## 离线模型

离线模型下载到这台设备上运行：识别与翻译的内容不会离开这台设备，使用时不需要 API Key，也不联网。在「设置 → 离线模型」里管理。离线模型默认不下载，安装包里也不带；没有在用时，Wisp 不为它们占用内存，也不启动任何进程。

### 有哪些模型

| 模型 | 用途 | 下载大小 | 适合的设备 |
| --- | --- | --- | --- |
| PP-OCRv6 Tiny | 文字识别，最快；49 种语言，**不识别日文** | 6.0 MB | 任何设备，CPU 即可流畅运行 |
| PP-OCRv6 Small | 文字识别，速度与准确度均衡；50 种语言（含简体与繁体中文、英文、日文） | 30 MB | 任何设备，CPU 即可流畅运行 |
| PaddleOCR-VL-1.6 | 文字识别，擅长表格、公式与复杂版面；三种识别模式都支持 | 1.8 GB | 8 GB 以上内存的 Apple 芯片，或 3 GB 以上显存的显卡；只有 CPU 时可以用，但明显较慢 |
| Index-Translate 2B | 翻译，轻快；150 种语言 | 1.2 GB | 8 GB 以上内存，CPU 也流畅 |
| Index-Translate 9B | 翻译，译文质量更高；150 种语言 | 5.4 GB | 16 GB 以上内存的 Apple 芯片，或 7 GB 以上显存的显卡；只有 CPU 时明显较慢 |

- 大小与设置页的显示一致（1 GB 按 1024 MB 计）。
- 每个模型卡片上有一个标记：「适合本机」「较慢」「内存不足」或「待检测」，按这台设备的内存、芯片与显卡得出。Windows / Linux 要在推理组件下载之后才能检测显卡，在那之前需要显卡的模型显示「待检测」；换了显卡或更新驱动后，可以点「重新检测显卡」。标为「较慢」「内存不足」或「待检测」的模型仍然可以下载，下载前会再确认一次（面板里就地下载时也一样）。「待检测」的模型下载时先装推理组件、检测显卡，检测出较慢或内存不足时停在「已暂停」并写出原因，点「继续」确认后才下载模型本身。只有集成显卡时按在 CPU 上运行的速度评估。
- 许可：PP-OCRv6、PaddleOCR-VL 与 Index-Translate 以 Apache-2.0 许可发布；设置页底部有各项目官方页面的链接。

### 推理组件

模型由两个开源的推理组件运行。第一次下载需要它的模型时，组件会一起下载（同一个任务，进度合并显示）：

| 组件 | 版本 | 许可 | 运行哪些模型 | 下载大小（macOS / Windows / Linux） |
| --- | --- | --- | --- | --- |
| llama.cpp（官方预编译的 llama-server） | b11669 | MIT | PaddleOCR-VL、Index-Translate | 12 MB / 31 MB / 29 MB |
| ONNX Runtime（官方 CPU 构建的动态库） | 1.28.3 | MIT | PP-OCRv6，以及 PaddleOCR-VL 的版面检测 | 32 MB / 5.5 MB / 8.7 MB |

- 推理组件总是从官方的 GitHub 发布页下载。Windows 上 ONNX Runtime 的发布包有 75 MB，Wisp 只按区间取出其中需要的动态库（约 5.5 MB），设置页也按这个实际下载量显示；服务器不支持按区间读取时才退回下载整个包。
- 显卡加速：macOS 用 Metal；Windows 与 Linux 用 llama.cpp 的 Vulkan 构建，NVIDIA、AMD、Intel 的显卡都可以用，没有可用的 Vulkan 驱动时自动改在 CPU 上运行。PP-OCRv6 与版面检测总是在 CPU 上运行。
- 设置页底部的「推理组件」列出版本与大小。还有已下载的模型用到它时不能单独删除；删除最后一个用到它的模型之后，就可以删除。

### 下载

- 点模型卡片上的「下载 · 大小」开始；还需要推理组件时，卡片上会注明「另需推理组件 N MB」。也可以直接在「设置 → 翻译」的默认模型或「设置 → OCR → OCR 模型」的下拉里选一个还没下载的离线模型，确认「下载并使用」。
- 一次下载一个文件，多个模型按顺序排队。下载中显示进度、速度与剩余时间，可以暂停、继续或取消（取消会删除已下载的部分）。网络中断时已下载的部分会保留，点「重试」接着下载。退出 Wisp 时，正在进行的下载变为「已暂停」，下次点「继续」即可，不会自动继续。
- **下载源**（「设置 → 离线模型 → 下载源」）：「自动」（默认）同时询问 ModelScope 与 Hugging Face，选先响应的一个，出错或长时间过慢时换另一个源接着下载；也可以只用 ModelScope（国内访问通常更快）或只用 Hugging Face。两个源上的文件内容相同。下载使用系统代理。
- **校验**：每个文件的大小与 SHA-256 都记录在 Wisp 里，边下载边计算，一致才会安装；不一致时丢弃这个文件、换一个源再试一次，仍不一致就报错。开始之前会检查磁盘空间是否足够。
- 设置窗口不在前台时，下载完成会发一条系统通知。
- Wisp 更新后如果换了某个模型的文件，卡片上会提示有新版本，可以在「更多操作」里重新下载；不会自动重新下载。

### 选用

- 在模型卡片上点「用于识别」或「用于翻译」，或在「设置 → 翻译」的默认模型、「设置 → OCR → OCR 模型」的下拉里选「离线模型」一组里的模型。在卡片上再点一次，改回默认模型。下拉里选一个还没下载的模型时，确认后开始下载，**下载完成后才切换过去**，下载期间照常用原来的模型；下载期间你又改了选择，就以你后来的选择为准。
- **离线模型的选择只属于这台设备**，不随[多设备同步](#多设备同步)：每台设备的算力不同，同步也不会把这台设备从离线改回云端。选了离线模型时，它优先于风格绑定的模型与默认模型；在下拉里改选模型服务的模型，会同时取消这台设备的离线选择。
- 翻译面板的「⋯ → 切换模型」与 OCR 的「重新识别 ▾」里也有已下载的离线模型，只对这一次生效。
- 引导的「接入模型」一步下方有「不想填 API Key？使用离线模型」，提供两档组合：**轻量**（PP-OCRv6 Small + Index-Translate 2B，约 1.3 GB，大多数设备都能流畅运行）与**高质量**（PaddleOCR-VL + Index-Translate 9B，约 7.2 GB，擅长表格与复杂版面、译文更好），按这台设备的适配结果标出推荐。选好后下载在后台进行，可以先继续引导，进度在「设置 → 离线模型」里查看。
- 用到一个还没下载完的离线模型时，面板里显示下载按钮或下载进度，下载完成后自动继续这一次的翻译或识别；截图已经不在时，点「重新截图」即可。

### 能做什么、不做什么

- **文字识别**：PP-OCRv6 支持纯文本与段落两种模式，不支持结构化。PaddleOCR-VL 三种模式都支持：结构化模式先检测版面，再逐块识别标题、正文、表格与公式，结果按区域一段一段出现；较小的截图直接整张识别。个别区域识别失败时跳过它、继续识别其余部分，结果下方会提示「部分区域未能识别」。
- **截图直接翻译**：先识别，再用当前的翻译模型翻译；翻译也选了离线模型时，全程都在这台设备上完成。
- **离线翻译只负责翻译**：润色与校对需要模型服务的模型，用离线模型时面板会说明「离线翻译模型只负责翻译」，不会改用云端；需要时在「⋯ → 切换模型」里为这一次换一个模型服务的模型，或在设置里改回模型服务。「提升译文」与词典式结果在离线模型上按普通翻译处理。风格的要求与命中的术语会作为约束交给模型。
- **出错时不会改用云端**：离线模型加载或运行失败时，面板显示原因与建议，不会把内容转交给模型服务。

### 内存与运行

在「设置 → 离线模型 → 运行」里：

| 设置 | 说明 |
| --- | --- |
| 闲置后释放内存 | 1 / 5（默认）/ 15 / 30 分钟没有使用，就释放模型占用的内存与显存，下次使用时重新加载；模型文件保留 |
| 使用 GPU 加速 | 默认开启（macOS 用 Metal，Windows / Linux 用 Vulkan）。出现异常或识别结果为空时可以关闭，改在 CPU 上运行 |
| 立即释放内存 | 有模型加载在内存里时可以点，马上释放 |

- 模型在第一次使用时加载，之后连续使用不再重新加载。**第一次加载可能较慢**：模型文件还不在系统的磁盘缓存里，macOS 上第一次运行还要编译 GPU 着色器。例如 Index-Translate 2B 第一次加载约 10 秒，之后再加载约 1 秒。用显卡加速的模型下载完成后，Wisp 会在后台先加载一次（模型卡片上的圆点会闪动），把这段准备提前做完，第一次使用时就不用再等。
- 系统内存紧张时，Wisp 先释放没在使用的模型；内存严重不足时，正在使用的模型也会在这一次完成后释放。加载之前可用内存不够时，先释放其他空闲的模型，仍然不够就提示「可用内存不足」，不会硬加载。
- 换了模型或关闭 GPU 加速时，原来的模型在当前请求完成后释放。退出 Wisp 时推理进程随之结束；Wisp 意外退出时推理进程也会自行结束，下次启动还会清理残留的进程。

### 存放位置与删除

- 模型与推理组件保存在数据目录下的 `models/`（见[文件位置](#文件位置)）。页面顶部显示已占用的空间与磁盘的可用空间，「打开文件夹」在访达 / 资源管理器 / 文件管理器中打开它。
- 删除：模型卡片上的「更多操作 → 删除…」，原地确认。正在使用的模型先停止再删除；它被选用时，选择随之取消，回到默认模型。
- 不要手工改动 `models/` 里的文件。文件缺失或大小不对时，卡片显示「模型文件缺失或已损坏」，点「重新下载」即可。

### 性能参考

下面的数字在一台 Apple M5 的 Mac（32 GB 内存，macOS 26.4）上测得，开启 GPU 加速、模型已经加载；其他设备上会有差异，Windows 与 Linux 目前没有公开的数字。

| 模型 | 速度 | 常驻内存 |
| --- | --- | --- |
| PP-OCRv6 Small | 一张 1200 × 846 的截图约 0.4–0.5 秒 | 约 120 MB |
| PaddleOCR-VL-1.6 | 一整页文档的结构化识别约 4 秒出完，第一段约 1.8 秒出现 | 约 2 GB，整页文档的版面检测另需约 0.5 GB |
| Index-Translate 2B | 生成约 70 token/秒；一句话的翻译约 0.2–0.5 秒 | 约 1.4 GB |
| Index-Translate 9B | 生成约 20 token/秒 | 约 5.8 GB |

## PaddleOCR 云端识别

PaddleOCR 的文字识别服务可以作为一种模型服务添加，只用于 OCR：

1. 打开「设置 → 模型与服务」，添加服务，在模板里选「PaddleOCR」。
2. **服务地址**默认是 AI Studio 的任务接口 `https://paddleocr.aistudio-app.com/api/v2/ocr/jobs`；也可以填在 AI Studio 上部署的服务，或者自托管的 PaddleX 服务（地址以 `/ocr` 或 `/layout-parsing` 结尾）。地址下方会显示 Wisp 认出的接口类型。
3. **访问令牌**在 AI Studio 的访问令牌页面（`https://aistudio.baidu.com/account/accessToken`）获取，粘贴进来后点「测试连接」。自托管的服务不需要令牌时可以留空。
4. 在「设置 → OCR → OCR 模型」里选 PaddleOCR 的一个模型；单次也可以从「重新识别 ▾」切换。

预置的模型：

| 模型 | 识别模式 | 说明 |
| --- | --- | --- |
| PP-OCRv6 | 纯文本、段落 | 只识别文字，不支持结构化 |
| PP-StructureV3 | 三种都支持 | 结构化输出 Markdown（标题、表格等）；**较慢，每张几秒到几十秒（随服务负载变化）** |
| PaddleOCR-VL-1.6 | 三种都支持 | 表格、公式与复杂版面 |

模型表里可以手动添加服务支持的其他模型名；这个服务没有「获取模型列表」。

- **截图会上传到你配置的服务**：用 PaddleOCR 识别时，截图发给你填写的地址处理；AI Studio 是百度提供的服务，上传的内容按其条款处理。免费额度、计费与使用条款以 PaddleOCR 与 AI Studio 的官方说明为准；额度用尽或触发限流时，面板会给出对应的提示。不想上传时请改用离线模型。
- 任务接口是先提交、排队处理，面板显示「云端处理中…」，Wisp 隔一小段时间查询一次，最多等 2 分钟；完成后从服务给出的结果链接取回结果（这一步不带令牌）。
- 截图直接翻译时先识别，再用翻译模型翻译（PaddleOCR 不能用于翻译，翻译的模型下拉里也不列出它）。
- 访问令牌只保存在系统凭据存储里（与 API Key 相同），界面不回显，也不写进日志与诊断包。AI Studio 的访问令牌权限较大，不只用于 OCR，不要分享给他人。开启同步并勾选「API Key」时，它会像 Key 一样加密后同步到你的其他设备，不想这样时关闭「API Key」的同步。
- 自托管服务的地址只有本机与局域网地址（包括 Tailscale 等组网工具分配的 `100.64.0.0/10` 地址）可以用 `http://`，其余要用 `https://`。

服务的细节（鉴权方式、连接测试、错误分类）见[模型服务 · PaddleOCR](providers.md#paddleocr文字识别服务)。

## 多设备同步

Wisp 可以经你自己的 WebDAV 存储，在多台设备之间同步设置与使用记录；Mac、Windows 与 Linux 可以混用。没有 Wisp 账号，也不经过中转服务器，数据在本机加密后才上传（见[同步与隐私](#同步与隐私)）。同步默认关闭，在「设置 → 同步」开启。

### 同步哪些内容

「设置 → 同步 → 同步内容」里每一类都可以单独关闭，连接之前也可以先调整。每台设备各自决定同步哪几类。

| 开关（默认都开） | 包括 |
| --- | --- |
| 设置与模型服务 | 大部分设置、模型服务（包括 PaddleOCR 服务）与默认模型、翻译风格（包括自定义风格）、术语表 |
| API Key | 模型服务的 Key（包括 PaddleOCR 的访问令牌），加密后随模型服务一起同步；需要先打开「设置与模型服务」 |
| 剪贴板历史 | 文本、富文本、链接、代码、颜色等条目，以及收藏与收藏的名称；不含文件条目 |
| 验证码 | 剪贴板历史里认出的验证码（见[识别出的内容](#识别出的内容)）；需要先打开「剪贴板历史」。关闭后验证码只留在这台设备上 |
| 剪贴板图片 | 剪贴板里的图片与识别历史的原始截图，单张不超过 10 MB，更大的只留在本机 |
| 识别历史 | 识别结果与缩略图；只在这台设备开启了「设置 → OCR → 识别历史」时同步 |

**按系统分别同步**：全局快捷键、风格快捷键、双击修饰键、复制等待时间与面板材质只在同一系统的设备之间同步——几台 Mac 共用一套，Windows、Linux 各自一套，Mac 上 <kbd>⌥</kbd> 开头的快捷键不会被带到 Windows 上。剪贴板的「排除的应用」与「应用内粘贴键」会把各台设备添加的条目合并起来，每台设备只使用属于自己系统的条目。

**只属于这台设备**（不同步）：开机时启动、开发者模式、剪贴板记录开关、跳过疑似密钥、识别历史开关、「通用 → 高级」里的日志级别与内存选项、离线模型的选择与「设置 → 离线模型」里的全部选项（下载的模型文件也不同步），以及同步本身的设置。窗口位置、引导进度等运行状态，以及 Wisp 自动探测到的模型能力（例如「未确认」的模型是否支持图片）也由每台设备各自保存。

### 剪贴板怎么同步

- 新的复制、再次复制、收藏与取消收藏、收藏的名称、删除与清空都会同步：在一台设备上删除或清空，其他设备上对应的记录也会删除。「收藏」分组是否折叠只属于这台设备。
- 粘贴只影响这台设备：在一台设备上粘贴某条记录，不会改变它在其他设备上的位置；再复制一次同样的内容，才会把它移到各台设备的最前面。
- 同步来的条目同样要经过这台设备的规则——排除的应用、跳过疑似密钥、记录的类型、单条大小上限与保留设置，不符合的不导入。这台设备关闭了剪贴板记录时，不导入其他设备的新条目，删除与收藏照常同步。
- 按保留设置（最多条数、保留天数）自动清理的旧条目不算删除，不会传到其他设备；保留设置本身会同步，各台设备最终清理到同样的范围。服务器上保存的历史同样受保留设置限制（收藏的条目除外），识别历史受「最多保存条数」限制，不会无限增长。
- **验证码按同一时间各自删除**：验证码的到期时间随条目一起同步，复制 10 分钟后到期时，每台设备按这个时间各自删除，与自动清理一样不算删除、不会传到其他设备；到期前在任意一台设备上收藏了它，各台设备都会保留。收到时已经过期的验证码不会导入，服务器上保存的这一条随保留设置清理。不想让验证码离开这台设备，关闭「同步内容」里的「验证码」：这台设备不再上传验证码，也不导入其他设备的验证码（收藏的验证码按普通条目同步）。
- 剪贴板面板开着时，其他设备的新条目会直接插进列表；列表刚刚移动过的那一下单击不会粘贴，以免点错。

### 连接

1. 打开「设置 → 同步」，点「连接 WebDAV…」。
2. 在「服务」里选一个（可选）：坚果云、123 云盘、Nextcloud、群晖 NAS 或自定义。它只用来预填地址，并提示应用密码在哪里申请。
3. 填写服务器地址、账号与应用密码，点「测试连接」。Wisp 分三步检查：「连接与登录」「读写权限」「服务器上的数据」——最后一步告诉你服务器上「尚无同步数据」，还是「已有 2 台设备的同步数据 · 最近更新于 3 天前」。
4. 测试通过后，按需调整「同步内容」，再设置或输入同步密码（见下文），点「连接」。macOS 上系统可能会请求访问钥匙串，选择「允许」即可。

常见服务的填法：

| 服务 | 服务器地址 | 账号与应用密码 |
| --- | --- | --- |
| 坚果云 | `https://dav.jianguoyun.com/dav/` | 账号是坚果云的登录邮箱；应用密码在坚果云网页版的「账户信息 › 安全选项 › 第三方应用管理」中添加 |
| 123 云盘 | `https://webdav.123pan.cn/webdav` | 在 123 云盘网页版的 WebDAV 设置里开启，使用那里显示的账号与密码 |
| Nextcloud | `https://云盘地址/remote.php/dav/files/用户名/` | 应用密码在「个人设置 › 安全 › 设备与会话」中创建 |
| 群晖 NAS | `https://NAS 地址:5006/` | 在套件中心安装 WebDAV Server 并启用 HTTPS；建议为 Wisp 单独建一个账号，填它的密码 |
| 其他 WebDAV 服务 | 服务提供的 WebDAV 地址 | 服务支持时，为 Wisp 单独申请一个应用密码 |

- Wisp 只在这个地址下的 `wisp/` 文件夹里读写（「测试连接」时会建好它），不碰其他文件。
- 地址要以 `https://` 开头，不能带 `?`、`#` 或账号。只有局域网地址可以用 `http://`（例如 `http://192.168.1.20:5005/`、`http://nas.local:5005/`），否则密码会以明文经过网络。Wisp 使用 HTTP Basic 认证。
- 应用密码连接后只保存在系统凭据存储里（钥匙串、凭据管理器或系统密钥环），不会回显。

### 同步密码

同步密码用来在本机加密数据，每台设备连接时输入同一个。「测试连接」之后，这一节按服务器上的情况分三种：

| 服务器上 | 你要做的 |
| --- | --- |
| 尚无同步数据（第一台设备） | 「设置同步密码」并「再输入一次」：至少 12 个字符，不要与应用密码、账号或服务器地址相同。也可以点「生成一个」，Wisp 生成一个随机密码并填好——先把它存进密码管理器。生成的密码只显示、不提供复制按钮，以免它进入剪贴板历史 |
| 已有同步数据（之后的设备） | 「输入同步密码」，即第一台设备上设置的那个。本机的数据会与服务器上的合并：服务器上已有的设置优先，本机独有的模型服务、术语与历史会保留 |
| 本机之前就在同步这份数据 | 「重新连接」：输入同步密码即可继续，本机尚未上传的改动会继续同步。换了应用密码、或在 Linux 上重启后需要重新输入密码时就是这种情况 |

加入已有的同步数据**不会删除这台设备上已有的数据**：本机独有的模型服务、风格与术语会上传；剪贴板与识别历史取两边的并集。比其他设备上的某次删除或清空更早的本机条目会留在这台设备上，但不会上传，所以不会在其他设备上重新出现。

这台设备以前就在同步这份数据、之后再连接回来时不同：它离开期间其他设备上的删除与清空会照常在这里生效。

**忘记同步密码将无法读取服务器上的数据**：Wisp 不保存同步密码本身，服务器上也只有密文，没有找回的办法，请把它保存在密码管理器里。忘记之后怎么办见[忘记同步密码](#忘记同步密码)。

点「连接」后回到同步页。设置类的数据通常几秒内就同步完；剪贴板与识别历史在后台继续上传与下载，状态行显示进度（「同步中 · 120 / 1000」），期间可以照常使用 Wisp。

### 自动同步

「自动同步」默认开启：改动后自动上传；使用 Wisp 时取回其他设备的改动。具体来说：

| 什么时候 | 做什么 |
| --- | --- |
| 这台设备上有改动（设置、Key、剪贴板、识别历史） | 约 2 秒后上传；连续改动时最晚约 10 秒 |
| 打开剪贴板面板 | 取回其他设备的改动，新条目随即出现在列表里（距上次检查至少 5 秒） |
| 打开翻译、OCR 或输入面板 | 取回其他设备的改动（距上次检查至少 1 分钟） |
| 打开托盘菜单、切换到设置窗口 | 同上（距上次检查至少 15 秒） |
| Wisp 已在运行时再次打开它 | 马上检查一次 |

- Wisp **不会定时在后台联网**：只在这台设备上有改动时上传（在其他应用里复制也算），只在你使用 Wisp 时取回其他设备的改动——所以另一台设备上的改动，要等你在这台设备上使用 Wisp 时才会出现。启动后，第一次联网发生在你第一次使用 Wisp（打开面板、托盘菜单或设置窗口）时。
- 没有新改动时，一次检查只是一个很小的请求。
- 关闭「自动同步」后，本机的改动照常记下，只在你点「立即同步」（同步页或托盘菜单）时同步。「立即同步」随时可用，不受上面的间隔限制。
- 暂时连不上服务器（断网、超时、服务器繁忙）时，状态行显示「暂时无法连接，稍后自动重试」，不弹任何提示；之后在你使用 Wisp 时隔一段时间再试（从 1 分钟起逐渐拉长，最长 30 分钟）。
- 需要你处理的问题（应用密码或同步密码不对、空间已满等）会暂停自动同步：状态行写明原因与建议，托盘状态行显示「同步需要处理」，点一下打开「设置 → 同步」；处理之后点「立即同步」即可恢复。
- 同步成功时没有任何提示，也从不发系统通知；设置窗口开着时，其他设备的改动会直接出现在窗口里。

### 冲突

冲突自动处理，不弹对话框：

- 同一项在两台设备上都改过时，以最后一次改动为准；不同项的改动互不影响——例如一台改了目标语言、另一台改了字号，两个改动都会保留。
- 模型服务、风格与术语按条目合并：两台设备各自新增的都会保留；同一个服务在两边都改过时，以最后保存的那一份为准。
- 删除会同步：在一台设备上删除的模型服务（连同它的 Key）、自定义风格、术语与剪贴板记录，其他设备上也会删除。正在编辑的服务如果已在其他设备上删除，保存时会提示「已在其他设备上或配置文件里删除，刚才的改动没有保存」。
- 两台设备的 Wisp 版本不同时，旧版本暂时不认识的设置会原样保留，等这台设备更新之后再应用。

### 只同步一部分

- 关闭「设置与模型服务」或「API Key」期间，这台设备的改动照常记下，但不上传，也不应用其他设备的改动；重新打开后，两边的改动按先后合并。
- 关闭「剪贴板历史」或「识别历史」期间，这一类不再同步；之后这台设备上传过的这类记录会从服务器上移除，其他设备上已有的保留。重新打开时，与服务器上的记录重新合并。
- 关闭「剪贴板图片」后，这台设备不再上传图片。
- 关闭「验证码」后，这台设备复制的验证码不再上传，其他设备的验证码也不再导入。

### 忘记同步密码

Wisp 不保存同步密码本身，也没有找回的办法。已经连接的设备不受影响，照常同步（它们保存的是由同步密码算出的密钥）；但新设备无法加入，已连接的设备在「更新密码…」里也需要输入同步密码。

要重新开始：在连接时输入同步密码的地方点「忘记了？」一行的「清除并重新开始」，确认后就在原地设置一个新的同步密码并连接（在「更新密码…」里应用密码可以一直留空，沿用已保存的那一份）；也可以在已连接的设备上点「清除服务器上的数据」，再点「连接 WebDAV…」，填写应用密码并设置新的同步密码。其他设备再用新的同步密码重新连接。各设备本机的数据都还在，重新连接后会重新合并、上传。

同步密码不能直接修改；想换一个时，同样先清除服务器上的数据，再用新密码重新连接。

### 断开同步与清除服务器上的数据

两者都在同步页的最下面，点击后原地确认：

| 操作 | 结果 |
| --- | --- |
| 断开同步 | 只影响这台设备：停止同步，删除本机的同步记录与保存的密码。本机的设置与历史保持不变，服务器上的数据与其他设备照常。本机还有改动没有上传时，确认时会提示，断开后不会再上传。服务器地址与账号会保留，之后点「连接 WebDAV…」、填写应用密码并输入同一个同步密码就能重新连接 |
| 清除服务器上的数据 | 删除服务器上的全部同步数据，**所有设备都会停止同步**（其他设备的状态行显示「服务器上的同步数据已被清除」），这台设备也随之断开。各设备本机的数据不受影响。要继续同步，在一台设备上重新连接并设置新的同步密码，其他设备点「重新连接…」，输入新的同步密码。无法撤销 |

断开同步的设备上传过的数据，以及它在「设备」列表里的一行，会留在服务器上，直到清除服务器上的数据。要换一个服务器，先断开同步，再用新的地址连接。

### 同步状态与提示

同步页「服务器」一节的状态行：「同步中 · 120 / 1000」「已同步 · 2 分钟前」「尚未同步」「有改动等待同步」「暂时无法连接，稍后自动重试」，或者下表中需要处理的问题。「测试连接」失败时也给出同样的原因与建议。

| 提示 | 怎么办 |
| --- | --- |
| 无法连接到服务器 | 检查网络或代理；恢复后会自动重试 |
| 账号或应用密码不正确 | 在「更新密码…」里重新输入应用密码 |
| 服务器拒绝了读写 | 确认这个账号可以读写这个目录；有的服务需要先单独开启 WebDAV |
| 服务器上找不到这个地址 | 检查服务器地址是否完整，例如末尾的 `/dav` 有没有漏掉 |
| 服务器空间已满 | 在服务器上腾出空间，或关闭「剪贴板图片」以减少占用 |
| 服务器暂时出了问题 | 稍后会自动重试；反复出现时检查服务的运行状态 |
| 这个地址需要使用 https | 只有局域网地址可以用 http；断开后用 `https://` 开头的地址重新连接 |
| 同步密码不正确 | 在「更新密码…」里重新输入同步密码 |
| 服务器上的同步数据已被清除 | 点「重新连接…」：设置新的同步密码，或输入其他设备上设置的新密码 |
| 服务器上的数据来自更新版本的 Wisp | 把本机的 Wisp 更新到最新版本后再同步 |
| 找不到已保存的密码 | 在「更新密码…」里重新输入应用密码与同步密码 |
| 无法读取系统凭据存储 | 点「立即同步」重试，系统弹出授权提示时选择「允许」 |
| 有一台设备的同步数据无法读取 | 其他设备不受影响；在那台设备上再同步一次通常可以恢复 |

错误详情（状态行下可以展开）只含 HTTP 状态码、错误种类这类信息，不含地址与文件名，可以放心贴进 Issue。

## 同步与隐私

- **端到端加密**：上传之前，所有同步内容——设置、Key、剪贴板、识别历史、图片，以及设备的名称与系统——都在本机加密，而且能发现篡改：服务商、服务器和网络上的人都读不到内容，被改动或调换的文件会被当作损坏而拒绝。加密使用 ChaCha20-Poly1305，密钥由同步密码经 PBKDF2-SHA256（60 万次迭代）派生；同步密码本身不离开这台设备，也不保存。
- **服务器能看到什么**：`wisp/` 文件夹里文件的数量、大小与修改时间，以及每台设备访问服务器的时间与 IP 地址。由此可以推断出有几台设备在同步、你大致在什么时候使用 Wisp、同步内容的总量，以及单张图片的大致大小。另有一个未加密的小文件 `vault.json`，记录格式版本、随机生成的标识、创建时间与密钥派生参数，供新设备核对同步密码；它不含任何同步内容。
- **同步密码要够强**：拿到服务器上这些文件的人，可以离线反复猜测同步密码。密码越长越难猜；建议用「生成一个」得到的随机密码，并保存在密码管理器里。
- **为 Wisp 单独申请应用密码**：WebDAV 的密码通常能访问整个网盘。不要填网盘的登录密码，尽量用为 Wisp 单独申请的应用密码；服务支持时，把它限制在一个文件夹，或者用单独的子账号（例如在群晖上为 Wisp 建一个只能访问一个共享文件夹的账号）。不再使用时，随时可以在服务商那里撤销。
- **凭据保存在哪里**：应用密码与由同步密码派生的密钥合成一项，只保存在系统凭据存储里（服务名 `wisp-sync`，见[文件位置](#文件位置)），不写进配置文件、日志与诊断包，界面进程也拿不到。服务器地址或账号改了之后，Wisp 不会把旧密码发给新的地址；服务器把下载转到其他主机（例如 CDN）时，也不会把账号密码带过去。Linux 没有 Secret Service 时只保存在本次运行中，重启后要在「更新密码…」里重新输入应用密码与同步密码。macOS 上从 0.1.1 及更早的版本更新上来后，第一次同步时钥匙串可能会询问，输入登录密码并选「始终允许」。
- **Key 只用在原来的地址上**：同步的 Key 记着设置它时服务的地址。服务的地址在其他设备上改到了别的主机、而 Key 没有跟着更新时，Wisp 会删掉这台设备上的旧 Key、提示重新填写，不会把旧 Key 发往新地址。
- **自定义请求头随模型服务同步**：模型服务的自定义请求头是服务设置的一部分，只要打开「设置与模型服务」就会随服务同步（同样在本机加密后上传），不受「API Key」开关控制，也不像 Key 那样只用在原来的地址上——服务的地址在其他设备上改到别的主机后，这些请求头会随请求发往新地址。如果你把网关之类的凭据填在请求头里（例如 `cf-aig-authorization`），又不想让它离开这台设备，请关闭「设置与模型服务」的同步。
- **服务器上的回收站与历史版本不受 Wisp 控制**：Wisp 删除或改写服务器上的文件（删除、清空历史、按保留设置整理、清除服务器上的数据）之后，坚果云、Nextcloud 等服务可能还会把旧文件在回收站或历史版本里保留一段时间。这些副本同样是加密的，但会占用空间；需要彻底删除时，到服务商那里清空回收站与 `wisp/` 文件夹的历史版本。
- **日志与诊断包**：同步在日志里只记录阶段、请求数、字节数、耗时、HTTP 状态码与错误种类，不记录服务器地址、账号、密码、同步密码、文件名、设备名与任何同步内容。诊断包里的服务器地址、账号与这台设备的同步编号替换为 `***`，也不含本机的同步数据库。

### 设备丢失时

如果一台已连接的设备丢失或被盗：

1. 到服务商那里撤销这台设备上 Wisp 使用的应用密码（这样它即使被解锁也连不上服务器），再为 Wisp 新建一个应用密码。
2. 在一台还在使用的设备上打开「设置 → 同步 → 更新密码…」，填入新的应用密码并「测试连接」；在同步密码一节点「忘记了？」一行的「清除并重新开始」，确认后设置一个**新的**同步密码并连接。服务器上用旧密钥加密的数据随之删除，之后的数据换用新的密钥，丢失的设备上保存的密钥对新数据无效。
3. 其他设备会显示「服务器上的同步数据已被清除」：点「重新连接…」，输入新的应用密码与新的同步密码。
4. 服务商有回收站或历史版本时，把其中 `wisp/` 文件夹的旧文件也清掉。

丢失的设备本机上的数据（设置、剪贴板历史等）不受同步保护，取决于那台设备的系统账户密码与磁盘加密。

### 快捷键

- **全局快捷键**：点击录制，按下新组合即生效；「测试」让你按一下确认能收到；可以恢复默认或清除。录制时会检测冲突——红色表示无法使用（系统保留、被其他程序占用、与另一个动作重复），黄色表示可能冲突但仍可使用。检测到 Easydict、Bob、Raycast、QQ 等应用也在用同一个组合时会提示。
- **风格快捷键**：按下即用该风格翻译选中的文字。
- **扩展触发**（默认全部关闭）：
  - **浮标**：选中文字后旁边出现一个小圆点，点一下即翻译；
  - **双击修饰键**：快速按两下指定的修饰键翻译选中的文字，间隔可选 200 / 300 / 400 ms；
  - **鼠标按键**：用中键、后退键、前进键触发指定动作，可以要求长按以免误触。

- **高级 · 复制等待时间**：读不到选中文字、改为模拟复制时等待剪贴板更新的时间（50–500 ms）。个别应用复制得慢、划词偶尔拿不到文字时调大一点。

### 模型与服务

- **服务列表**：每个服务显示地址、模型数与状态（未设置 Key、连接正常、需重新测试）。
- **服务编辑器**：名称、协议、区域（有区域变体的服务）、Base URL（下方实时显示最终请求地址）、API Key、连接测试。
  - **高级**：自定义请求头（不要在这里填 Key）；**关闭思考**（翻译不需要模型「思考」，按服务的方式关掉以降低延迟）；输出长度参数（被拒绝时自动换用另一个）；合并系统提示（部分视觉模型需要）；剥离 `<think>` 标签；同时发送两种鉴权头（部分中转站需要）；Gemini 的 Key 放在 URL 参数里；连接 / 首字 / 中断三个超时。
  - **模型**：拉取模型列表，勾选启用；「图片」列表示是否支持识图（未确认的模型识别失败时会自动标为不支持），「推理」列标出推理模型并可选推理档位；可以手动添加模型 ID；「重置能力缓存」让 Wisp 下次请求时重新探测。
  - **删除服务**：同时从系统凭据存储删除它的 Key，并清除引用它的默认模型。
- **PaddleOCR**：模板里的「PaddleOCR」是只用于 OCR 的文字识别服务，编辑器里是服务地址、访问令牌、预置模型与连接测试，没有「获取模型列表」（见[PaddleOCR 云端识别](#paddleocr-云端识别)）。
- **默认模型**：翻译（划词、输入翻译、润色、校对）与 OCR 分别选。下拉按组列出：离线模型（这台设备上运行，未下载的也列出并注明大小，选择后确认「下载并使用」）、文字识别服务（PaddleOCR，只在 OCR 里出现）与各模型服务的模型（OCR 只列支持图片的模型）。选离线模型只对这台设备生效（见[离线模型 · 选用](#选用)）。

协议、Base URL 规则、各选项的具体效果与各服务的注意事项见[模型服务](providers.md)。

## 文件位置

| 内容 | macOS | Windows | Linux |
| --- | --- | --- | --- |
| 配置（`settings.json`、`styles.json`、`glossary.json`、`state.json`） | `~/Library/Application Support/wisp/` | `%APPDATA%\wisp\` | `~/.config/wisp/` |
| 数据（剪贴板 `clipboard.db` 与 `blobs/`、识别历史；开启同步时还有 `sync.db` 与 `sync/`） | `~/Library/Application Support/wisp/` | `%LOCALAPPDATA%\wisp\` | `~/.local/share/wisp/` |
| 日志（`wisp.log`，2 MB × 5 个滚动） | `~/Library/Logs/wisp/` | `%LOCALAPPDATA%\wisp\logs\` | `~/.local/state/wisp/logs/` |
| 离线模型与推理组件（数据目录下的 `models/`） | `~/Library/Application Support/wisp/models/` | `%LOCALAPPDATA%\wisp\models\` | `~/.local/share/wisp/models/` |
| API Key（包括 PaddleOCR 的访问令牌） | 钥匙串：服务 `wisp`，账户为服务 ID | 凭据管理器 →「Windows 凭据」→ 普通凭据 `<服务 ID>.wisp` | Secret Service：服务 `wisp`，账户为服务 ID（「密码和密钥」里显示为 `keyring:<服务 ID>@wisp`） |
| 同步凭据（应用密码与同步密钥） | 钥匙串：服务 `wisp-sync`，账户 `account` | 凭据管理器 →「Windows 凭据」→ 普通凭据 `account.wisp-sync` | Secret Service：服务 `wisp-sync`，账户 `account`（显示为 `keyring:account@wisp-sync`） |

Linux 的路径遵循 `XDG_CONFIG_HOME` / `XDG_DATA_HOME` / `XDG_STATE_HOME`。配置文件可以手工编辑，保存后 Wisp 会自动重新加载（开启同步时，手工改动同样会同步到其他设备）；文件损坏时 Wisp 会保留上一次有效的设置或备份原文件后恢复默认，并在设置窗口里提示。

`sync.db` 是同步的本机记录（各项的最新状态、读到了哪里、还有哪些改动待上传），`sync/` 存放上传与下载过程中的临时文件；同步关闭时不会创建，断开同步时删除。服务器上的同步数据在你填写的地址下的 `wisp/` 文件夹里。

**彻底卸载**：开启过同步的话，先在「设置 → 同步」断开同步（会删除本机的同步记录与同步凭据）；如果这是最后一台还在同步的设备、以后也不再用同步，改点「清除服务器上的数据」（同样会断开），或者之后直接删除服务器上的 `wisp/` 文件夹。然后卸载应用，删除上表中的配置、数据与日志三个目录（离线模型在数据目录的 `models/` 里，随之删除），并删除上表中的凭据条目——钥匙串与密钥环里搜索 `wisp`（同步凭据是 `wisp-sync`），Windows 凭据管理器里是以 `.wisp` 结尾的普通凭据与 `account.wisp-sync`（或在卸载前先在设置里删除所有服务）。

## 常见问题与排错

**按快捷键没有反应**

1. 看托盘状态行：如果显示「N 个快捷键未生效」，点它打开「设置 → 快捷键」，红色的项会写明原因（被系统或其他程序占用、系统拒绝注册）。换一个组合或用「改用 …」切换到备选键。
2. 其他划词 / 截图工具（Easydict、Bob、PopClip、Snipaste、QQ 等）可能占着同一个组合，在设置里会有提示。
3. 在密码框等安全输入状态下，快捷键可能不触发。
4. Linux Wayland 会话不支持全局快捷键。有 X11 会话可选时请切换过去（Ubuntu 22.04 / 24.04 的「Ubuntu on Xorg」、Debian 的「GNOME on Xorg」，或 Xfce、MATE、Cinnamon 等桌面）；Ubuntu 25.10 起（包括 26.04 LTS）和 Fedora 43 起的默认 GNOME 已经没有 X11 会话，只能在系统设置里把快捷键绑定到 `wisp-desktop --trigger translate_input` 等命令（AppImage 写它的完整路径）。

**划词后打开的是输入框，或提示读不到选中的文字**

- macOS：确认「系统设置 → 隐私与安全性 → 辅助功能」里 Wisp 是打开的。更新版本后需要先移除旧条目再重新添加。
- 少数应用不提供选中的文字，Wisp 会模拟复制；如果仍然拿不到，把「设置 → 快捷键 → 高级 → 复制等待时间」调大一些。
- Windows：以管理员身份运行的程序无法读取。先复制，再用输入翻译。
- Linux Wayland：无法读取选区，先复制再粘贴进输入框。

**截图是黑的、只有桌面壁纸，或提示需要屏幕录制权限**

macOS 需要「屏幕录制」权限，授权后必须重新启动 Wisp（面板里有「重新启动 Wisp」按钮）。如果之前授权过、从 0.1.1 及更早的版本更新上来后失效（见下一条），到「系统设置 → 隐私与安全性 → 屏幕录制」里移除 Wisp 再重新添加。「截图失败」提示也可能是其他截图工具正占用屏幕，或者显示器刚刚变化，稍后重试即可。Linux 的 Wayland 会话下「截图失败」的说明是「这一版在 Wayland 会话下无法截图。需要截图时，请切换到 X11 会话」：这一版还没有接入 Wayland 的截图门户（Screenshot portal），重试也不会成功；有 X11 会话可选时注销后在登录界面切换过去（Ubuntu 22.04 / 24.04 的「Ubuntu on Xorg」、Debian 的「GNOME on Xorg」，或 Xfce、MATE、Cinnamon 等桌面），Ubuntu 25.10 起（包括 26.04 LTS）和 Fedora 43 起的默认 GNOME 已经没有 X11 会话（见 README 的 Linux 安装说明）。

**更新后权限失效，或钥匙串反复询问**

Wisp 用固定的自签名证书签名，更新版本后已授予的权限保持有效。从 0.1.1 及更早的版本（只有 ad-hoc 签名）更新上来时，macOS 会把新版本当成新应用：托盘会提示「更新后需要重新授权」，按 README 的说明在系统设置里移除旧条目后重新授权；钥匙串询问时输入登录密码并选「始终允许」。这一步只需要做一次，之后的更新不再需要。

**提示「还没有接入模型」或「还没有能识别图片的模型」**

在「设置 → 模型与服务」添加服务并选择默认模型，或者在「设置 → 离线模型」下载一个离线模型（见[离线模型](#离线模型)）。OCR 也可以用 PaddleOCR 或支持图片的模型（例如 GPT-4.1 / GPT-5 系列、Claude、Gemini、Qwen-VL）；模型列表的「图片」列显示「未确认」的模型也可以尝试，识别失败时 Wisp 会自动把它标为不支持。

**离线模型下载很慢或总是失败**

- 「网络中断」：已下载的部分会保留，点「重试」接着下载。下载使用系统代理，检查网络或代理。
- 很慢或下载源不可用：在「设置 → 离线模型 → 下载源」改成 ModelScope 或 Hugging Face 试试（国内访问 ModelScope 通常更快）。
- 「文件校验没有通过」：下载的部分已丢弃，重试即可；反复出现时换一个下载源。
- 「磁盘空间不足」：下载前会按剩余的大小再留一些余量检查空间，清理后重试。

**离线模型加载失败、出错或识别结果为空**

错误卡片里写明了原因，常见的有：

| 提示 | 怎么办 |
| --- | --- |
| 可用内存不足 | 关闭一些程序，或改用更小的模型（例如 Index-Translate 2B、PP-OCRv6）后重试 |
| 显卡加速出错 / 识别结果为空 | 关闭「设置 → 离线模型 → 使用 GPU 加速」后重试 |
| 缺少 Microsoft Visual C++ 运行库（Windows） | 从微软官网安装 Visual C++ 可再发行组件（x64）后重试 |
| 系统缺少推理组件需要的库（Linux） | 更新系统，或安装缺少的库后重试 |
| 推理组件没能启动 | 可能被安全软件拦截：允许后重试，或在「设置 → 离线模型 → 推理组件」里删除后重新下载 |
| 模型文件缺失或已损坏 | 在模型卡片上点「重新下载」 |
| 加载模型超时 | 重试；硬盘较慢时第一次加载可能更久 |

第一次加载模型较慢是正常的（见[内存与运行](#内存与运行)）。离线模型出错时不会改用云端；需要时可以在面板的「⋯ → 切换模型」或「重新识别 ▾」里为这一次换一个模型。

**提示「离线翻译模型只负责翻译」**

润色与校对需要模型服务的模型。在「⋯ → 切换模型」里为这一次选一个模型服务的模型，或在「设置 → 翻译」把默认模型改回模型服务（同时会取消这台设备的离线选择）。

**PaddleOCR 识别失败**

- 「服务拒绝了这个访问令牌」：检查令牌是否填错、过期或没有权限，到 AI Studio 的访问令牌页面重新复制。
- 「无法识别的服务地址」：地址应以 `/api/v2/ocr/jobs`（AI Studio 的任务接口）、`/ocr` 或 `/layout-parsing`（部署的服务）结尾；公网地址必须用 `https://`。
- 额度用尽或触发限流：稍后再试；额度以官方说明为准。
- 超时：PP-StructureV3 每张从几秒到几十秒不等，任务最多等 2 分钟；需要快一些时改用 PP-OCRv6 或 PaddleOCR-VL-1.6。

**连接测试失败**

- 「服务拒绝了这个 Key」（401 / 403）：检查 Key 是否填错、过期、没有额度或没有该模型的权限。
- 404：多半是 Base URL 不对。对照下方显示的最终请求地址，确认版本段（`/v1` 等）是否正确；服务的路径不带版本段时在末尾加 `#`。
- 超时或网络错误：检查网络与代理。Wisp 使用系统代理设置，本机地址（Ollama、LM Studio）直连。
- 「部分可用」：模型列表获取失败但流式请求正常，可以手动添加模型 ID 后使用。
- 错误卡片里可以展开详情，查看服务返回的原始信息。各类错误的含义见[模型服务 · 错误提示](providers.md#错误提示)。

**译文被截断，或提示「模型思考耗尽了输出额度」**

推理模型会先花掉一部分输出额度「思考」。在错误卡片里点「调高上限」或「切换模型」；也可以在服务的高级设置里确认「关闭思考」选的是对应服务的方式，或在模型表里把推理档位调低。

**粘贴没有粘进去，只复制了**

面板会提示原因（见[使用条目](#使用条目)），内容已经在剪贴板里，手动粘贴即可。macOS 上最常见的原因是没有授予辅助功能权限。

**剪贴板没有记录某些内容**

检查：记录是否被暂停；「设置 → 剪贴板」里该类型是否勾选；是否从排除名单里的应用复制；内容是否被当成疑似密钥跳过（托盘会闪一下）；是否超过单条大小上限。Linux Wayland 会话不记录剪贴板。

**同步的状态行显示错误，或「测试连接」失败**

按状态行里的原因与建议处理，各种提示的含义见[同步状态与提示](#同步状态与提示)；处理完点「立即同步」。连接测试的三步里，失败在「连接与登录」多半是地址、账号或应用密码不对，失败在「读写权限」多半是账号没有写入权限或空间已满。

**另一台设备上的改动没有出现**

- Wisp 只在你使用它时取回改动：打开剪贴板面板、托盘菜单或设置窗口，或者点「立即同步」（见[自动同步](#自动同步)）。
- 两台设备的「同步内容」都要勾选这一类；识别历史还要求这台设备开启了「设置 → OCR → 识别历史」。
- 快捷键与面板材质只在同一系统的设备之间同步，开机启动等选项只属于本机（见[同步哪些内容](#同步哪些内容)）。
- 剪贴板条目要符合这台设备的规则（排除的应用、跳过疑似密钥、记录的类型、大小上限与保留设置）；文件条目与超过 10 MB 的图片不同步。
- 两台设备的 Wisp 版本差得多时，旧版本不认识的新设置会先保留，更新之后再应用。

**Linux：托盘图标不见了 / 重启后 API Key 丢失**

GNOME 需要「AppIndicator and KStatusNotifierItem Support」扩展；没有托盘时功能照常可用（快捷键与设置窗口）。Key 丢失说明系统没有可用的 Secret Service：安装并解锁 GNOME Keyring 或 KWallet 后重新填写 Key。同步的应用密码与同步密码也是同样的情况，重启后在「设置 → 同步 → 更新密码…」里重新输入。

**「检查更新失败」**

Wisp 从 GitHub（`github.com/yzlltyyh/wisp/releases/latest/download/latest.json`）读取更新清单，失败多半是网络无法访问 GitHub：检查网络或代理后在托盘里再点一次「检查更新」。也可以随时从 Releases 页面手动下载新版本；不想联网检查时把「设置 → 通用 → 检查更新」设为「关闭」。

**面板出现的位置不合适**

划词翻译的位置在「设置 → 翻译 → 面板位置」（跟随选区 / 跟随光标 / 屏幕中央），剪贴板在「设置 → 剪贴板 → 面板位置」（可以记住上次拖到的位置）。

## 诊断导出与反馈

遇到问题时：

1. （可选）把「设置 → 通用 → 高级 → 日志级别」临时调到「调试」，复现一次问题。
2. 打开「设置 → 关于 → 诊断信息」，点「导出诊断包」，选择保存位置。
3. 到 [GitHub Issues](https://github.com/yzlltyyh/wisp/issues/new/choose) 用「问题报告」模板新建一个 Issue，把这个 zip 作为附件上传，并写明 Wisp 版本（「设置 → 关于」）、系统版本、操作步骤、期望与实际结果；能附截图或录屏更好。
4. 排查完把日志级别改回「信息」。

**不要在 Issue、截图或日志里贴出 API Key**（同步用的应用密码与同步密码也一样）；截图里出现 Key、个人信息或剪贴板内容时请先遮掉。**安全问题不要开公开的 Issue**，私下报告的方法见 [SECURITY.md](../SECURITY.md)。

诊断包里有：最近的日志（最多 12 MB）、脱敏后的 `settings.json`、`styles.json`、`state.json`、版本与系统信息（`app_info.json`，含同步的状态，不含设备名；还有离线模型的状态：已下载的模型与大小、推理组件的版本、是否已加载、最近一次失败的种类、内存大小与显卡名称，不含路径）、取词方式的统计（`selection-stats.json`）。**不含**：API Key、请求头的值、URL 里的查询参数、术语表、同步服务器的地址、账号与这台设备的同步编号（替换为 `***`）、应用密码与同步密码、本机的同步数据库，以及任何原文、译文、剪贴板内容或截图——这些本来就不会写进日志。导出前可以解压检查。
